# Hub de continuidad y presión

Versión web publicada del hub de continuidad y presión del servicio de agua potable, mantenido por el equipo CAMI YAKU de SUNASS.

Es una única página autocontenida (`index.html`) que reúne los visores cartográficos y de tablero, la metodología de cálculo de los indicadores, y los reportes del seguimiento nacional.

Sitio: https://eilerssunass.github.io/continuidad-presion-web/

## Sobre este repositorio

Contiene solo la página publicada. El proyecto de origen, con los scripts de procesamiento y el perfil de datos, se mantiene en un repositorio privado aparte.
